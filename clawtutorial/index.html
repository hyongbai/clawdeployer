4 个实际场景

产品经理 → 需求直达代码

"在注册页面加手机号验证"
→ Claude Code 写代码、开 PR
→ 推推回复 "PR #234 已创建"

测试 → Bug 直达修复

发 Bug 描述 + 复现步骤
→ 定位问题、修代码、补测试
→ "修复 PR #235 已创建"

开发 → 随时随地协作

地铁上用手机推推
"review PR #230 安全变更"
→ 回复问题列表 + review comment

运营 → 自然语言出数据

"统计本月各渠道注册转化率"
→ 写脚本 + 跑数据
→ 返回 Excel 文件

踩坑经验

#问题状态
1大文件写入被杀（30KB+ 截断）已解决
2空回复 / 收不到结果已解决（streamTo）
3权限弹窗卡住已解决（--approve-all）
4默认超时太短（120s）已解决（改 600s）
5网络受限取决于环境
6做事不彻底靠 task 描述约束

1-4 是技术问题，已有 workaround

🆚 为什么必须是龙虾

AI 能做什么都差不多，差异在谁触发、在哪触发、什么时候触发

三个本质差异

CC / Copilot / CodexOpenClaw / 安全龙虾
触发方式你打开工具、主动发起定时 / Webhook / 群聊 @
交付位置你一个人的终端/网页团队群聊，所有人可见
生命周期关窗口就停7×24 云端持续运行
CC/Codex 是个人工具
龙虾是团队的 7×24 AI 同事

场景对比

🔴 构建失败

用 CC：收邮件 → 开终端 → 拉日志 → 喂 AI → 通知同事
用龙虾：Webhook 自动触发 → 分析 → 直接在群里 @相关人

📊 数据日报

用 ChatGPT：每天手动导出 → 粘贴 → 复制 → 发群
用龙虾：每天 9:00 自动拉取 → 生成 → 发到群里

💡 群里提需求

用 Codex：开发打开工具 → 复制需求 → 生成 → 手动提 PR
用龙虾：产品 @龙虾 → 写代码提 PR → 群里回复链接

⚠️ 差评激增

用网页 AI：它不会主动找你，等你想起来可能过了一天
用龙虾：定时监控 → 主动推送告警到群里

写代码、做分析这些能力，大家都有。

龙虾的不同在于——它活在你们的群里，不需要你打开任何工具，不需要你在电脑前，事情就已经办了。
