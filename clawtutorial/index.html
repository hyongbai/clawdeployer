03 记忆与人格系统

让 AI 记住你、变成你想要的角色

记忆系统 — AI 终于有了长期记忆

类型存什么举例
用户记忆你是谁、你的偏好"用户是测试负责人，偏好表格汇总"
项目记忆在做什么、进度、决策"本轮迭代 6/15 截止"
反馈记忆你纠正过 AI 的行为"不要用 emoji、回复要简洁"
参考记忆外部信息指针"Bug 跟踪在 Jira PAYMENT 项目"

ChatGPT：关窗口就忘 → 龙虾：一个月后依然记得你的偏好

06 为什么必须是龙虾？

和 ChatGPT / Copilot / Codex 的本质差异

三个本质差异

Claude Code / Copilot / CodexOpenClaw / 安全龙虾
触发方式你打开工具、主动发起定时任务 / Webhook / 群聊 @
交付位置你一个人的终端或网页团队群聊中，所有人可见
运行周期关窗口就停7×24 云端持续运行

CC/Codex 是你的个人工具，龙虾是团队的 7×24 AI 同事

场景对比

🔥 构建失败了

用 CC：收邮件→打终端→喂日志→自己通知同事
用龙虾：Webhook 自动触发→分析原因→直接在群里 @相关人

📋 每天早上的数据日报

用 ChatGPT：打开网页→导数据→粘贴→复制→发群
用龙虾：每天 9:00 自动拉数据、生成日报、发到群

💡 产品群里提了需求

用 Codex：手动复制需求→生成代码→提 PR→回群
用龙虾：产品 @龙虾→自动写代码提 PR→群里回复链接

⚠️ 差评突然变多了

用任何网页 AI：它不会主动找你
用龙虾：定时监控→发现激增→主动推送告警
